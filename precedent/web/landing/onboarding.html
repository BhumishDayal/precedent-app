Connect your fleet

Three steps: an API key, a collector that streams SMART readings, and the channels where your on-call should hear about it. Agents can connect over MCP.

Needs smartmontools + Python Outbound HTTPS only One API key

  1. Create an API key

    On the Precedent server, set PRECEDENT_API_KEYS to a comma-separated list of keys. Every request then sends one of them in the X-Precedent-Key header.

    On the Precedent server

    export PRECEDENT_API_KEYS=pk_live_xxx,pk_live_yyy

    On each machine that reports

    export PRECEDENT_KEY=pk_live_xxx

  2. Install the collector

    The collector reads every disk with smartctl and POSTs the readings to /v1/telemetry. Run it from cron or systemd.

    pip install httpx
PRECEDENT_URL=https://<your-precedent-host> PRECEDENT_KEY=$PRECEDENT_KEY python -m precedent.collector

    Or send a reading yourself

    Any script can post to the REST API directly.

    curl -X POST $PRECEDENT_URL/v1/telemetry \
  -H "X-Precedent-Key: $PRECEDENT_KEY" \
  -H 'content-type: application/json' \
  -d '{"serial":"1QHPN2VX","model":"WDC WUH722222ALE6L4","smart":{"197":120},"site":"sac2"}'

  3. Connect channels

    Set the environment variables for the channels you use on the Precedent server. Each alert carries the evidence and a link to the incident.

    Slack
    SLACK_WEBHOOK_URLSLACK_SIGNING_SECRET

    Set the app's interactivity URL to <host>/slack/actions so the Swap and Wait buttons work.

    Dial
    DIAL_API_KEYDIAL_FROM_NUMBER_IDONCALL_PHONE

    A call or text to the on-call, who replies 1 to swap or 2 to wait.

    Discord, Teams, webhook

    Paste the incoming-webhook URL for Discord or Microsoft Teams, or a generic webhook URL for your own bots and agents.

    Test a channel: send a sample alert with POST /api/integrations/test/slack 
    curl -X POST $PRECEDENT_URL/api/integrations/test/slack -H "X-Precedent-Key: $PRECEDENT_KEY"

For agents

An SRE agent, a datacenter ops bot or Claude can ask Precedent directly over MCP, with the same API key.

claude mcp add --transport http precedent https://<your-precedent-host>/mcp-public/ --header "X-Precedent-Key: $PRECEDENT_KEY"
